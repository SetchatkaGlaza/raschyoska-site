# Расчёска — сайт парикмахерской

Адаптивный одностраничный сайт для парикмахерской «Расчёска» в Вологде. Проект сделан на HTML, CSS и JavaScript без сборщика и тяжёлых зависимостей; подходит для публикации через GitHub Pages.

## Возможности

- Навигация по разделам и мобильное меню.
- Прайс-лист с категориями и поиском услуг.
- Галерея работ с фильтрами и просмотром изображений.
- Акции и интерактивные купоны.
- Отзывы и раскрытие дополнительного списка на мобильных устройствах.
- Контакты: телефон, ВКонтакте, Telegram, WhatsApp и маршрут на Яндекс Картах.
- Форма-заявка: формирует текст заявки и помогает перейти в сообщество ВКонтакте.
- Поддержка клавиатурной навигации, видимого фокуса и `prefers-reduced-motion`.
- Иконка вкладки браузера (favicon) и web manifest.
- Метаданные Open Graph и Twitter Card для предпросмотра ссылки с изображением в поддерживаемых мессенджерах и соцсетях; после публикации проверьте, что URL репозитория совпадает с адресом в метаданных.
- JSON-LD для поисковых систем.

## Запуск локально

Можно открыть `index.html` напрямую. Для проверки через локальный сервер рекомендуется:

```bash
npm start
```

Команда использует `npx serve`; при первом запуске может потребоваться интернет. Альтернатива:

```bash
python3 -m http.server 8000
```

## Проверка проекта

```bash
npm run check
node --check js/main.js
node --check js/data.js
```

Скрипт проверки контролирует наличие локальных ресурсов, файлов CSS/JS, уникальность HTML `id` и существование внутренних якорей. Это статическая проверка, а не полноценный автоматизированный браузерный тест.

## Адаптивность

В стилях предусмотрены контрольные точки для планшетов и телефонов (`900px` и `640px`), а также системная настройка уменьшения анимации. Перед публикацией рекомендуется проверить сайт в браузере на ширинах 320, 360, 390, 430, 768, 1024, 1280 и 1440 px, проверить меню, вкладки прайса, поиск, галерею, акции, форму заявки и телефонные ссылки. Также проверьте портретную и альбомную ориентацию мобильного устройства.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `raschyoska-site`.
2. Загрузите **содержимое этой папки**, чтобы `index.html` лежал в корне репозитория.
3. В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment.
4. Отправьте изменения в ветку `main`. Workflow из `.github/workflows/pages.yml` выполнит публикацию. Готовый адрес появится в настройках Pages.

## Что обязательно согласовать с владельцем

- Подтвердить адрес, телефоны, часы работы, цены, скидки и ссылки на социальные сети.
- Подтвердить разрешение на публикацию фотографий, логотипа и отзывов. Использование открытых источников само по себе не означает разрешения на повторную публикацию.
- Проверить, что форма записи корректно объясняет пользователю следующий шаг: сайт не отправляет заявку в CRM автоматически, а подготавливает текст и открывает ВКонтакте.
- Уточнить, актуальны ли рейтинг и количество отзывов в разметке Schema.org.
- После выбора домена настроить `canonical`, абсолютный `og:image` и `sitemap.xml`.

## Где редактировать контент

- Цены и категории: `js/data.js`.
- Поведение меню, фильтров, галереи и формы: `js/main.js`.
- Внешний вид и адаптивные правила: `css/style.css`.
- Тексты, адрес, контакты, SEO-метаданные и блоки страницы: `index.html`.
- Фотографии: `assets/img/`.
